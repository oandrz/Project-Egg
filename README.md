# Project Egg (Chefnut)

A modern Android recipe application built with Kotlin and Jetpack Compose.

## Quick Start

1. Clone the repository
2. Open in Android Studio
3. Run `./gradlew app:assembleDevelopDebug` to build
4. The app now uses Jetpack Compose as the main UI framework

For detailed information, please refer to the documentation in the [`docs`](docs/) directory.
